# Base suave del consejo

`loading-tip-mist.svg` es la fuente vectorial editable, creada en código con curvas y gradientes suaves. `loading-tip-mist.png` es su exportación RGBA transparente de 1600×180 para Skia en Android/iOS/web. No es pixel art y se dibuja con muestreo lineal. El texto es independiente y se alinea abajo con el área segura. Los assets anteriores se conservan intactos.
